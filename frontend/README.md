# Frontend

React + TypeScript + Tailwind frontend для игры "Воздушный шар".

## Запуск

```bash
npm install
npm run dev
```

По умолчанию Vite откроется на `http://localhost:5173` и проксирует `/api` на backend `http://localhost:8080`.

Для другого адреса backend можно задать:

```bash
VITE_API_URL=http://localhost:8080 npm run dev
```
